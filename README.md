# Panen Ranum — Landing Page

Landing page profil **Panen Ranum**, usaha keluarga yang menawarkan sayuran hidroponik dari Bogor sejak 2020. Website ini dibuat sebagai proyek **Special Task Webdev Bayucaraka 2027** menggunakan HTML dan CSS saja.

## Fitur
- Navbar dan hero section dengan tombol navigasi.
- Profil usaha, tiga keunggulan, katalog produk, dan penjelasan budidaya hidroponik.
- Informasi kontak serta tautan WhatsApp untuk menanyakan stok dan kunjungan.
- Tampilan responsif untuk desktop dan ponsel.

## Menjalankan
Buka file `index.html` dengan browser. Tidak perlu instalasi tambahan atau server.

## Struktur
- `index.html` — konten dan struktur semantik halaman.
- `style.css` — seluruh styling dan responsivitas.
- `assets/panen-ranum-logo.png` — logo Panen Ranum hasil ekstraksi dari PDF yang diberikan.
- `assets/favicon.png` — ikon tab browser.

## Catatan sebelum publikasi
- Ilustrasi sayuran dan kebun bersifat sementara, **bukan foto asli Panen Ranum**. Ganti dengan foto asli saat tersedia.
- Konfirmasi ejaan akun Instagram `@panemranum` dan izin publikasi nomor WhatsApp sebelum website dipublikasikan.
- Harga sengaja tidak dicantumkan karena ketersediaan dan harga produk dapat berubah.
- Klaim bebas pestisida tidak dicantumkan sampai praktik budidayanya terkonfirmasi.
- Perjelas produk "salad" dan asal buah yang dijual sebelum menambah detail katalog.
