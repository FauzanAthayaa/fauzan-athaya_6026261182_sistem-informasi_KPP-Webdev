# Panen Ranum — Landing Page

Website profil **Panen Ranum**, usaha keluarga yang menyediakan sayuran hidroponik dari Bogor sejak 2020. Proyek ini dikembangkan untuk Special Task Webdev Bayucaraka 2027.

## Tentang website

Landing page ini memperkenalkan cerita usaha, sistem budidaya hidroponik, produk unggulan selada dan pakcoy, serta informasi pemesanan dan kunjungan kebun. Produk lain meliputi daun mint, sayuran salad, dan pilihan buah sesuai ketersediaan.

## Fitur

- Navigasi ke bagian Tentang Kami, Produk, Kebun Kami, dan Kontak.
- Informasi usaha dan tiga keunggulan layanan.
- Katalog produk dengan tautan WhatsApp untuk menanyakan stok.
- Informasi kunjungan kebun dan kontak Instagram.
- Tampilan responsif untuk desktop dan perangkat seluler.

## Teknologi

- HTML5 (semantic HTML)
- CSS3 (tanpa JavaScript dan framework)

## Struktur file

```text
index.html
style.css
README.md
assets/
  panen-ranum-logo.png
  favicon.png
```

## Menjalankan website

Buka `index.html` di browser. Untuk GitHub Pages, gunakan **Settings → Pages → Deploy from a branch → main / (root)**.
